# Product Overview

This project is a game prototype named "Projetor Simulator: Chamados da TI". The product turns the everyday chaos of classroom technical support into a short, comedic, browser-based game loop focused on diagnosing projector failures and solving them under pressure.

## Core Capabilities

- Fast, readable mini-game loops for hardware troubleshooting scenarios
- A mission structure based on calls, diagnosis, repair, and validation
- Comedic classroom and maintenance themes adjusted for light replayability
- React-based frontend interactions with immediate feedback and retry loops

## Target Use Cases

- Teaching the team how to design readable troubleshooting interactions
- Prototyping game loops, point-of-failure moments, and humorous feedback states
- Validating a short, highly focused browser game built around one mechanic at a time

## Value Proposition

- A compact, clear production workflow for the game prototype
- A fast design-to-implementation path consistent with cc-sdd
- Reusable mini-game patterns that can later be extended into more complex missions
