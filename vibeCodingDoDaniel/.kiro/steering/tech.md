# Technology Stack

## Architecture

Standard Single Page Application (SPA) architecture bootstrapped via Create React App.

## Core Technologies

- **Language**: JavaScript (ES6+)
- **Framework**: React 19.3
- **Runtime**: Node.js

## Key Libraries

- **react-scripts**: Encapsulates the build toolchain (Webpack, Babel, ESLint).
- **@testing-library/react**: Utilities for testing React components.
- **web-vitals**: Core web vitals monitoring.

## Development Standards

### Code Quality
- Uses ESLint configured via `react-app` standard rules.

### Testing
- Jest with React Testing Library.

## Development Environment

### Common Commands
```bash
# Dev: npm start
# Build: npm run build
# Test: npm test
```

## Key Technical Decisions

- Maintained as a standard Create React App to avoid build configuration overhead (no ejection).
